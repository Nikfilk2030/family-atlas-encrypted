# Границы публикации

## Что уже разрешено

Владелец явно разрешил публичное семейное дерево и клиентский код без шифрования в **этом существующем репозитории**

Данные и семь изображений при реорганизации извлечены из уже опубликованной страницы. Перенос в отдельные файлы не добавляет нового семейного материала

## Чего в репозитории нет

- Полного рабочего дела исследования, локальных поисковых журналов и переписки
- Настроек Hermes, пользовательских профилей, сессий или памяти агента
- Токенов, ключей, access-state, секретов браузера или `.env`
- Несвязанных рабочих или личных данных

Папка `data/` является публичной моделью приложения, не разрешением экспортировать всё исследование. `.gitignore` помогает не добавить служебное случайно, но не заменяет проверку конкретных файлов перед коммитом

## Источники и права

Сохраняйте происхождение каждого текста и изображения, ID записи, URL, подпись и оговорки о тождестве. Публичность страницы не делает все утверждения доказанными и не меняет права на сторонние архивные изображения

Эта реорганизация не назначает новую общую лицензию архивным материалам и не разрешает поиск современных контактов родственников или обращения от имени владельца

## Проверка перед публикацией

```sh
python3 scripts/build.py --check
git diff --check
git status --short
git diff --stat
```

Добавляйте намеренные пути, не копируйте рабочую папку целиком. Не меняйте доступ, название репозитория, ветку Pages, историю Git или права участников без отдельного поручения

## Историческое название

`family-atlas-encrypted` сохранено, чтобы не ломать существующий URL. Текущий сайт открыт, `payload.bin`, дешифратор и ключ в URL ему не нужны. Старые коммиты не являются текущими инструкциями по публикации
