# Карта архитектуры

## Поток сборки

`scripts/build.py` читает шаблон и исходники из `src/`, модель из `data/atlas.json` и семь опубликованных изображений из `assets/documents/`

Сборщик проверяет идентификаторы и ссылки, разрешает изображения только внутри `assets/`, встраивает их как data URI и создаёт один `index.html`

Порядок JavaScript важен: это не ESM-пакет и не приложение с bundler, страница должна открываться через `file://`

1. `graph_routes.js`
2. `atlas.js`
3. `timeline.js`
4. `graph_time.js`
5. `status_popover.js`
6. `timeline_host.js`

Модель встроена в `<script id="atlas-data" type="application/json">`. `safe_json()` экранирует границы inline-скрипта, но не меняет декодированные строки

## Основное состояние

Публичная точка входа для проверок: `window.familyAtlas`

- `model` содержит опубликованные записи, не геометрию предполагаемых дат
- `state` хранит выбор человека/семьи, фильтры, страницу и режим раскладки
- `boxes` содержит геометрию семейных областей
- `occurrences` содержит появления человека в разных семьях по ключу `family_id:person_id`
- `treeState` хранит логический центр, масштаб и намерение камеры
- `summaryFrames` соответствует реально нарисованным непрозрачным сводкам, а не полным резервам раскладки

Разделение `person` и `occurrence` принципиально: один человек может быть ребёнком в одной группе и родителем в другой

## Что искать в atlas.js

- `generationRanks`, `layout`: уровни от вашей семьи и размещение групп
- `renderGraph`: слои семейных сводок и подробных карточек
- `paint`, `commit`, `safeViewport`, `fitTree`: экранная проекция и камера
- `showPerson`, `showFamily`, `showTree`: пользовательская навигация
- `highlightRelation`, `showRelation`: реестровое родство
- `highlightContinuation`, `showContinuation`, `continuationsAt`: один человек между группами, точный выбор видимой линии
- `openDrawer`, `resizeDrawer`, `closeDrawer`: общая панель досье

## Не перепутать

**Геометрия не является историческим источником**

- Поколения выровнены относительно главной семьи, а не по максимальной глубине самых дальних предков
- Реальные даты рождения имеют точные координаты по общей шкале
- Неизвестные даты получают отдельный `placementYear` только для размещения, с явным предупреждением
- Смерть не становится рождением
- Архивный кандидат не становится родственником из-за общей группы или временной близости

**Обзор и детали имеют разную рисуемую геометрию**

Маршрут должен обходить актуальную карточку/сводку своего слоя. Резервный layout-прямоугольник не заменяет реальную непрозрачную поверхность. При свободном коридоре используется плавная кривая, при препятствиях безопасный обход

**Досье принадлежит приложению, не скрытой странице**

Переключение на «Таймлайн» не должно прятать хозяина досье или ломать resize. Возврат к дереву сохраняет камеру, действие «В дереве» выбирает точный ID

## Текущие границы

`atlas.js` остаётся главным модулем с общим состоянием. Реорганизация репозитория не превращает его в новую архитектуру и не меняет дизайн. Дальнейшее выделение компонентов следует делать небольшими проверяемыми шагами, сохраняя standalone-сборку
