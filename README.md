# Живой семейный атлас

[Открыть сайт](https://nikfilk2030.github.io/family-atlas-encrypted/) · [Инструкции для агентов](AGENTS.md) · [Карта кода](docs/ARCHITECTURE.md)

Автономное дерево с семейными группами, персональными досье, источниками, документами и режимами «Поколения / По годам»

Дерево и клиентский код опубликованы открыто по прямому разрешению владельца. Название `family-atlas-encrypted` историческое: шифрования и ключа в ссылке больше нет, адрес сохранён

## Открыть или собрать

Для просмотра достаточно скачать `index.html` и открыть его в браузере. Всё приложение, данные и изображения уже внутри файла, сервер и аккаунт не нужны

Сборка из исходников требует только **Python3.12+**, без Node.js, Hermes, внешних библиотек или доступа к сети

```sh
git clone https://github.com/Nikfilk2030/family-atlas-encrypted.git
cd family-atlas-encrypted
python3 scripts/build.py --check
```

Чтобы пересобрать после изменений:

```sh
python3 scripts/build.py
```

## Где что редактировать

| Путь | Назначение |
|---|---|
| [`src/`](src/) | Исходники интерфейса, камеры, линий, временной карты и таймлайна |
| [`data/atlas.json`](data/atlas.json) | Уже опубликованная модель людей, семей, связей, источников и атрибуции |
| [`assets/documents/`](assets/documents/) | Те же изображения, которые встроены в автономную страницу |
| [`scripts/build.py`](scripts/build.py) | Независимая офлайн-сборка и проверка ссылок в данных |
| [`scripts/format.py`](scripts/format.py) | Единый формат JS/CSS без Node.js |
| [`tests/`](tests/) | Переносимые проверки сборки и поведения в браузере |
| [`docs/`](docs/) | Архитектура, модель данных, разработка и границы публикации |
| `index.html` | **Сгенерированная страница, не редактировать вручную** |

Изменения интерфейса начинаются в `src/`, фактов и источников в `data/`, не в шестимегабайтном HTML

## Разработка и проверки

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python scripts/format.py --write
.venv/bin/python scripts/build.py
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

Установленный Chrome можно использовать вместо загрузки Chromium. Подробности, отдельные тесты и публикация: [DEVELOPMENT.md](docs/DEVELOPMENT.md)

GitHub Actions проверяет форматирование, актуальность `index.html` и браузерные регрессии при изменении кода, данных или тестов. Периодических заданий нет. Документационные правки не запускают тяжёлые проверки

## Что есть в атласе

- Полное дерево и настоящие поддеревья, семейные группы раскрываются до людей
- Цвета родства относительно выбранного человека, нажимаемые линии с пояснениями и источниками
- Режим «По годам» на том же дереве и отдельный список «Таймлайн»
- Люди без дат остаются около семьи с явно условным временным ориентиром, а не получают вымышленную дату рождения
- Досье, поиск, сравнение кандидатов, изображения документов, свёрнутые полные тексты источников
- Размер досье меняется перетаскиванием, управление доступно мышью, касанием и клавиатурой

## Достоверность и публикация

Семейный человек, исторический кандидат и предполагаемый родственник не становятся одной личностью из-за совпадения имени. Данные различают рассказы семьи, публикации, архивные индексы, оригинальные копии и гипотезы

В репозитории только опубликованная модель и необходимые исходники. Здесь нет полного служебного дела исследования, ключей, токенов, настроек аккаунтов или данных профиля агента

Открытая публикация не меняет авторские права на архивные изображения и тексты. Сохраняйте подписи, оговорки и ссылки на источники
