# Живой семейный атлас

[Открыть сайт](https://nikfilk2030.github.io/family-atlas-encrypted/)

Дерево опубликовано открыто по прямому разрешению владельца. Шифрование и ключ в ссылке больше не нужны. Название репозитория сохранено для совместимости со старой ссылкой.

## Как устроено

`index.html` — автономное приложение: HTML, CSS, JavaScript, структурированные семейные сведения и имеющиеся копии документов. Его можно скачать и открыть без сервера. Исходный клиентский код доступен внутри файла, внешние библиотеки и аккаунт не требуются.

Схема различает семейные рассказы, архивные записи, возможные совпадения и предполагаемые родственные связи. Найденная запись не означает доказанного родства. Содержимое семейного дерева не является набором подтверждённых биографий.

## Приватность и источники

Сайт и включённые сведения видны всем. Ключи, токены, настройки аккаунтов и служебные файлы профиля не публикуются. Открытая публикация не меняет авторские права на сторонние архивные изображения и тексты. При повторном использовании материалов сохраняйте атрибуцию и ссылки на источники.

## Разделы и управление

- «Дерево»: семейные группы с раскрытием до отдельных людей, поддеревья и цветные линии относительно выбранного человека; переключатель «Поколения / По годам» на той же карте; люди без дат остаются рядом со своей семьёй с подписью об условном временном ориентире, без записи вымышленных дат рождения
- Линии между семейными группами можно нажать мышью, пальцем или клавиатурой: откроются имя связующего человека, его роли в обеих группах и источники; если линии совпали, можно выбрать нужную связь
- «Таймлайн»: хронология рождений, приблизительные периоды, поиск и отдельный показ записей-кандидатов
- «Люди»: поиск по всем самостоятельным записям
- Профиль: главное, семья, жизнь, материалы, неясности и источники; длинные общие тексты свёрнуты
- Значки в правом верхнем углу карточек показывают происхождение сведений и наличие материалов; подсказка и нажатие раскрывают значение
- Размер досье меняется перетаскиванием его границы, на телефоне меняется высота
- Клик или тап по пустому месту карты снимает выделение; перетаскивание карты его не сбрасывает

Приложение автономное, без аналитики и внешних библиотек. Для чтения сайта не требуются аккаунты или ключи.
